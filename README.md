# Sessiz Kütüphanede Cips Açma Simülatörü

> **Resmi Uyarı:** Bu proje bir şaka değildir. Şaka gibi durması, şaka olmadığının kanıtıdır.

## Nedir bu?

İnsanlık tarihi boyunca iki ses vardır:
1. Bilginin fısıltısı
2. Cips paketinin ihaneti

Bu depo, ikinci sesin **akustik, etik ve mide kaynaklı** simülasyonunu sunar. Yazılım çalışır. Vicdan da çalışır. İkisi aynı anda çalışınca ortaya bu çıkar.

## Kurulum

```bash
git clone https://github.com/Tentivory/sessiz-kutuphanede-cips-acma-simulatoru.git
cd sessiz-kutuphanede-cips-acma-simulatoru
python3 cips.py
```

Bağımlılık yoktur. Sadece Python 3, bir miktar utanç ve tercihen kapalı bir oda.

## Bilimsel Yöntem

- Kütüphane taban gürültüsü: `18.0 dB`
- Toplumsal utanç eşiği: `87.3 dB`
- Örneklem: rastgele, çünkü hayat da öyle

Paket her denemede farklı bir ses çıkarır. Bu bir bug değil, doğanın kendisidir.

## Katkı

Pull request açmadan önce lütfen bir kütüphanede gerçekten cips açmayın. Teorik katkı yeter.

Issue açabilirsiniz. Sessizce.
